# AI时代的个人画像及个人上下文记录工具Myself介绍

> 跟 AI 聊天的人大概都有这个体验。不管你跟它聊过多少次，打开新窗口，它永远不记得你是谁。

你做什么工作，最近在愁什么，上周读过哪篇文章，它一概不知道。每次都要把背景重新讲一遍，讲得烦了，问题也就懒得问了。

我一直在想这件事。**大模型本身的能力已经不差，差的往往是它不了解你。** AI 公司管这个叫上下文，我更愿意叫它个人画像。同一个问题，了解你的 AI 和不了解你的 AI，给出的答案质量差得很远。

## 上下文从哪来

让人专门整理个人档案、写自我介绍，没人坚持得下去。我后来想到一个现成的东西，剪贴板。

**剪贴板是一个人数字生活里最诚实的记录。** 你复制什么，说明那一刻你在意什么。复制这个动作本身就是一次筛选，不用学，不用养习惯，你每天都在做。我自己的电脑开机一天，剪贴板会经过几十上百条内容，代码、文章段落、链接、待办、聊天记录，全在里面。

## 它做了什么

所以我做了马赛福，英文名 Myself。它常驻系统托盘，把你复制过的文本自动收进本地数据库。空闲的时候，AI 在后台把每条内容清洗一遍，提取标题，分成灵感、代码、文章、链接、待办几类，再打上标签。

**整个过程不用你管，你只管正常复制。** 需要用的时候按 `Ctrl + Alt + Space` 唤起，一个小窗口直接搜。

## 找回来，分三层

光收下来没用，收得越多越像垃圾场，关键是能不能找回来。这里我做了三层。

- **全文搜索**。输入关键词，毫秒级出结果。
- **AI 兜底**。直接搜不到时，AI 从你的话里拆出几个可能的搜索词分别再搜，把结果合并排重后给你。
- **AI 问答**。把搜到的资料连同你的问题一起交给模型，照着资料回答，末尾列出引用的来源。

AI 调用走你自己的 OpenAI 兼容密钥，接口地址和模型都可以换，费用也是你自己的。

## 真正让我觉得成了的，是汇总

每天夜里它把当天的条目交给 AI 生成一份日报，每周再出一份周报。

拿我自己跑了几天后的真实数据说。当时库里一共 **272** 条内容，**271** 条来自剪贴板，只有 **1** 条是我手动记的。周报先盘点，本周有记录的只有两天，一共 **58** 条，从里面拎出 **9** 个待办，然后按主题归类，告诉我这周的时间花在了哪几件事上，哪些事反复出现。

> 这份报告读起来有点扎心。它不关心你觉得自己在忙什么，只看你复制过什么。你以为这周在推进项目，报告说你的注意力一大半耗在部署和账号权限的杂事上。

**个人画像很难靠问卷画出来，它是从这些碎片的统计里自己长出来的。**

也有露馅的时候。分类统计里最多的是「其他」，125 条，快占一半。说明分类器还粗糙，很多内容它没看懂。这个我不打算藏着，工具的边界就摆在那里。

## 几个设计上的取舍

- **数据全部存在本机**，不经过任何第三方服务器。只有你自己配置了 API 密钥，内容才会发给你自己选的模型接口。
- **剪贴板默认全量收集**，不做敏感内容过滤，这一点要想清楚再用。
- **重复内容可选当日排重或全量排重**。
- 带一个简单的任务提醒，单次、每天、每周都行，到点弹系统通知。
- **应用本身免费开源。**
